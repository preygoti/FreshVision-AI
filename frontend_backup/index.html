Deep Learning System Architecture & Pipeline

MobileNetV2 + Grad-CAM

Our project utilizes Transfer Learning with an Inverted Residual Bottleneck CNN (MobileNetV2) pre-trained on ImageNet and fine-tuned for high-accuracy fruit freshness detection and degradation scoring.

MobileNetV2 Advantages

  • Depthwise Separable Convolutions: Reduces parameters by ~8× compared to regular Conv2D without accuracy loss.
  • Linear Bottlenecks: Prevents non-linearities from destroying valuable image details in manifold spaces.
  • Edge Ready: Capable of 30+ FPS real-time execution on mobile devices, Raspberry Pi, or supermarket checkout cameras.

Explainable AI (Grad-CAM) Formula

Grad-CAM calculates the importance weight \(\alpha_k^c\) of feature map \(A^k\) for class \(c\):

\(\alpha_k^c = \frac{1}{Z} \sum_{i} \sum_{j} \frac{\partial Y^c}{\partial A_{i,j}^k}\)

The visual attention map \(L_{\text{Grad-CAM}}^c\) is then computed with a ReLU activation:

\(L_{\text{Grad-CAM}}^c = \text{ReLU}\left(\sum_{k} \alpha_k^c A^k\right)\)

ReLU ensures the heatmap only captures features that positively contribute to the target class (e.g. rot spots, discoloration).

Frequently Asked Viva Questions (Ready Answers)

Q1: Why did you choose MobileNetV2 instead of building a basic CNN or using VGG16?
Answer: VGG16 has over 138 million parameters and is computationally heavy. Standard custom CNNs struggle with limited training data. MobileNetV2 uses Depthwise Separable Convolutions with only ~3.5 million parameters, reducing computational operations by ~8× while retaining ImageNet feature knowledge via transfer learning. This makes it ideal for real-time edge deployment.
Q2: How do you prove this isn't just basic color thresholding (e.g. green/yellow vs brown)?
Answer: We implemented Grad-CAM (Gradient-weighted Class Activation Mapping). It computes the mathematical gradient of the predicted class score with respect to the spatial feature maps of the final convolutional layer. This visualizes the spatial geometry, skin texture necrosis, and fungal spore patches that the CNN extracted, proving deep spatial representation learning.
Q3: What loss function and optimizer did you use, and why?
Answer: We used Categorical Cross-Entropy Loss combined with the Adam Optimizer (learning rate \(\eta = 0.0005\), \(\beta_1=0.9, \beta_2=0.999\)) with weight decay for L2 regularization. A StepLR learning rate scheduler was applied to reduce learning rate every 3 epochs to ensure smooth convergence without oscillations.
Q4: How did you prevent overfitting on the fruit images?
Answer: Three complementary strategies were implemented: (1) Data Augmentation (random horizontal flips, random rotations up to 20°, and ColorJitter for brightness/contrast), (2) Dropout regularizers (p=0.3 and p=0.2) in the classification head, and (3) Batch Normalization before non-linear activations.
